Install Ubuntu, step by step

From download to a secure, updated desktop or server: verify the image, make a USB installer, install, and harden the first boot.

LinuxPC configuration
ShareXLinkedInRedditFacebookEmail

Ubuntu is the most widely used Linux desktop, a common choice for servers, and a good way to give an older PC a second life. This guide takes you from download to a secure, updated system, for both the desktop and server editions. It assumes nothing beyond being comfortable restarting a computer and changing a boot option.

Which version to choose

Ubuntu publishes a release every six months, and every second April release is a long-term support (LTS) version with five years of standard security updates. For anything you rely on, choose the latest LTS. Interim releases get nine months of support, which suits people who want the newest features and do not mind upgrading often.

EditionUse it forMinimum hardware (practical)
DesktopLaptops and workstations, with a graphical interface4 GB memory (8 GB recommended), 25 GB disk, 64-bit processor
ServerServers and virtual machines, managed by command line1.5 GB memory, 5 GB disk; more for real workloads

1. Back up first

Installing can erase the disk. Copy everything you care about to another drive or cloud storage before you start, even if you plan to keep Windows alongside Ubuntu. If the PC uses BitLocker and you want to dual boot, save the BitLocker recovery key first: changing boot settings can trigger a recovery prompt.

2. Download and verify the image

Download the ISO from ubuntu.com/download, and the SHA256SUMS file from the same release folder. Verifying proves the file was not corrupted or tampered with:

# Linux
sha256sum ubuntu-*.iso

# macOS
shasum -a 256 ubuntu-*.iso

# Windows PowerShell
Get-FileHash .\ubuntu-*.iso -Algorithm SHA256

Compare the output with the line for your file in SHA256SUMS. On Linux you can let the tool compare for you:

sha256sum -c SHA256SUMS --ignore-missing

A result of OK means the image is exactly what Canonical published.

3. Make a bootable USB drive

Use a USB stick of 8 GB or more; it will be erased.

  • Windows: Rufus or balenaEtcher. In Rufus, select the ISO, keep the partition scheme as GPT for modern UEFI computers, and write in the recommended ISO mode.
  • macOS: balenaEtcher.
  • Ubuntu: the built-in Startup Disk Creator.

On Linux you can also write the image directly. Be very careful to pick the right device; dd overwrites whatever you point it at without asking:

lsblk                                    # find the USB stick, for example /dev/sdb
sudo dd if=ubuntu.iso of=/dev/sdb bs=4M status=progress conv=fsync

4. Prepare the computer

  • Boot order: open the boot menu at start-up, usually with F12, F10, F2 or Esc depending on the manufacturer.
  • Secure Boot: leave it on. Ubuntu supports it, and it protects the start-up process.
  • Storage mode: some laptops ship with Intel RST or "RAID" mode; if the installer cannot see the disk, switch to AHCI in the firmware settings (after backing up, as Windows may need adjusting first).

5. Try, then install

Choose Try or Install Ubuntu. Trying first lets you check that Wi-Fi, sound, the trackpad and the display work before you commit. Then start the installer:

  • Updates and drivers: tick the option to install third-party software for graphics and Wi-Fi hardware.
  • Disk: Erase disk and install Ubuntu replaces everything; Install alongside keeps Windows for dual booting.
  • Encryption: choose the encryption option under advanced features. If the laptop is lost, the data stays unreadable. Store the passphrase or recovery key somewhere safe, not on the same laptop.
  • Your account: use a strong password. This first account can use sudo, the Linux equivalent of administrator.

6. First boot: update and protect

Open a terminal (Ctrl+Alt+T) and run this first-boot script. Save it as first-boot.sh, make it executable with chmod +x first-boot.sh, and run it:

#!/usr/bin/env bash
# first-boot.sh - bring a fresh Ubuntu install up to date and switch on the basics
set -euo pipefail

echo "Installing all updates..."
sudo apt update
sudo apt full-upgrade -y
sudo apt autoremove -y

echo "Turning on the firewall: block incoming, allow outgoing..."
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw --force enable
sudo ufw status verbose

echo "Confirming automatic security updates are active..."
systemctl is-enabled unattended-upgrades
systemctl is-active unattended-upgrades

echo "Useful tools..."
sudo apt install -y git curl htop

echo "Done. Reboot if a new kernel was installed: sudo reboot"

If the computer has an NVIDIA graphics card, let Ubuntu pick the recommended driver:

ubuntu-drivers devices
sudo ubuntu-drivers install

7. Server edition: secure remote access

A server is usually managed over SSH. Install it, then use keys instead of passwords, which are far harder to guess or steal.

# On the server
sudo apt install -y openssh-server
sudo ufw allow OpenSSH

# On your own computer: create a key and copy it to the server
ssh-keygen -t ed25519 -C "you@example.com"
ssh-copy-id youruser@server-address

Once key login works, switch off password logins with a drop-in file, which survives package updates better than editing the main configuration:

echo "PasswordAuthentication no" | sudo tee /etc/ssh/sshd_config.d/50-no-passwords.conf
sudo sshd -t && sudo systemctl restart ssh

sshd -t checks the configuration first; if it reports an error, fix it before restarting, or you can lock yourself out. Keep your current session open until you have confirmed a new login works.

8. Ubuntu Pro

Ubuntu Pro is free for personal use on a small number of machines. It extends security maintenance to many more packages and adds Livepatch, which applies kernel security fixes without a reboot. Attach it with the token from your Ubuntu One account:

sudo pro attach YOUR_TOKEN
pro status

9. Set up backups

Open the built-in Backups app (Déjà Dup) and point it at an external drive or cloud folder. Then restore one file to prove it works. Our guide to the 3-2-1 backup rule explains how to build a plan that survives ransomware and theft.

Troubleshooting

  • The USB stick does not appear in the boot menu: rewrite it with Rufus in GPT mode, or try another USB port, preferably directly on the computer.
  • No Wi-Fi after install: connect with a cable, run the updates, then check Software & Updates > Additional Drivers.
  • Black screen after boot: at the boot menu, press E, add nomodeset to the line starting with linux, press F10, then install the recommended graphics driver.
  • Windows missing from the boot menu after dual boot: run sudo update-grub.
